# 📊 Sales Performance Analysis

## Project Overview

This project analyzes historical retail sales data using Python and Power BI to identify business trends, high-performing products, regional performance, and key sales metrics.

---

## Objectives

- Analyze sales performance
- Identify top-selling products
- Compare regional sales
- Calculate KPI metrics
- Build an interactive Power BI dashboard

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- GitHub

---

## Dataset

Sample Superstore Dataset

---

## Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Average Order Value
- Profit Margin

---

## Dashboard Features

- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Interactive Filters
  - Year
  - Region
  - Category
  - Segment

---

## Business Insights

- Technology generated the highest sales.
- West region performed best.
- Canon imageCLASS 2200 was the top-selling product.
- Profit margin remained around 12.47%.
- Sales varied significantly across months.
